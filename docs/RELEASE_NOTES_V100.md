# FC27 Academy Engine v1.0.0 — First public release

Version 1.0.0 is the first public release. It is internal build 1.24.39 (release candidate
packaging) with the version set to 1.0.0; there are no other changes. Existing careers and settings
carry over; no reset is required.

What it includes, in short:
- PlayStyle, PlayStyle+ and Role++ development for players FC27 generates, from real attribute
  growth across checkpoints, with waiting periods and lifetime limits; starting PlayStyles for new
  players.
- Optional PlayStyle / PlayStyle+ decline with age (off by default) and retirement handling.
- Save-aligned checkpoints: loading an older save restores the matching Academy Engine state.
- The in-game overlay (dashboard, players, development, timeline, events, settings).
- A Windows release with its own Python, an uninstaller, and a player README.

Development history up to this release is in the v1.24.x release notes in this folder.
Versions from here on follow 1.0.x (fixes) and 1.x.0 (new features).
